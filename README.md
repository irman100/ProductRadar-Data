# ProductRadar-Data

Открытое хранилище данных для Product Radar (сайт и Android).

**Нет платного OpenAI API.** Данные делятся на:
- `data/market/cny_rub.json` — ежедневный официальный курс CNY/RUB Банка России;
- `data/research/categories.json` — исследованные ниши с подтверждёнными источниками; до первого исследования массив пуст;
- `data/research/products.json` — конкретные товары и источники; до первого исследования массив пуст;
- `data/status.json` — состояние источников и время обновления.

Файлы `data/research/` нельзя выдавать за свежие только из-за обновления курса. Поля `researched_at`, `sources` и `confidence` обязательны для каждой опубликованной оценки.

## Использование
- Сайт и мобильное приложение загружают файлы из GitHub через HTTPS с проверкой полей.
- Публичные данные не содержат API-ключей, личных фотографий или конфиденциальных закупочных цен.
- Ежедневный workflow обновляет только официальный курс CNY. Для товаров/категорий требуется отдельный проверяемый исследовательский процесс.

## Источники
- Банк России: https://www.cbr.ru/development/SXML/
- Курсы на дату: https://www.cbr.ru/scripts/XML_daily.asp
