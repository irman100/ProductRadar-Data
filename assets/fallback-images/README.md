# Product Radar — резервные изображения

Хранить здесь только собственные, лицензированные или сгенерированные изображения. Для каждого файла указать в data/catalog/images.json fallback_image_url, fallback_image_type, fallback_note, источник и дату. Для synthetic_backup обязательна видимая подпись «Иллюстрация, не оригинальное фото товара». Изображение не подтверждает SKU, происхождение или спрос. Не считать пустую папку или запись в очереди созданным изображением.
