# Обогащение каталога: цены и изображения

- `python scripts/audit_images.py` — HTTP-проверка изображений и датированный отчёт; `--apply` обновляет поля аудита в индексе. Блокировки и тайм-ауты не означают удаление товара. Проверка не доказывает соответствие SKU и доступность в мобильном браузере.
- `python scripts/build_fallback_manifest.py` — очередь поиска/создания резервных изображений. Скрипт не генерирует и не скачивает фотографии. Резервный файл сохранять только с разрешением или как явно обозначенную иллюстрацию. Основной URL оставлять для реального SKU. Синтетика не повышает статус спроса и не допускается как доказательство в verified.
- `python scripts/enrich_average_prices.py --observations data/research/price_observations.example.json --apply` — пересчёт цен после ручной проверки источников. По умолчанию учитываются только наблюдения за последние 7 дней с датой, RUB, in_stock=true, match_confidence=exact_sku и price_type=public_unconditional_retail_offer; одна цена на площадку, минимум две площадки. Не смешивать размеры, комплектации и цвета с различной ценой; не использовать условные цены с картой/купоном. Поле average_sale_price_rub исторически названо так, но означает среднюю публичную цену предложения, НЕ среднюю фактическую цену сделок. При нехватке источников — null; единственная цена сохраняется в price_observations. Цена поставщика, маржа и спрос независимы.

Формат входного файла цен: объект, ключи — существующие product id, значения — массивы объектов с platform, url (точная карточка), price_rub, currency, observed_at (ISO), match_confidence, price_type, in_stock. Пустой пример не содержит цен. Скрипт не добывает цены из закрытых API.

Для отображения фронтенд должен предпочитать проверенный primary, при сбое загрузки переходить на fallback с подписью для синтетики. Поля в JSON сами по себе не изменяют интерфейс. Не выполнять деплой автоматически.
