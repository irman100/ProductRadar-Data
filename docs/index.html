1. Выберите категорию

Смотрите её размер, динамику и риски. Рейтинг ниже — ориентир, а не официальная статистика.

2. Откройте товары

Изучите фотографии-примеры, ограничения и ссылки на площадки. Некоторые карточки пока гипотезы.

3. Рассчитайте закупку

Уточните цены у фабрик, логистику, таможенные документы и возможные возвраты.

Рейтинг направлений для первой проверки

Оценки 0–100 — редакционные приоритеты для старта импорта, не объём продаж или вероятность прибыли.

Конкретные товары для изучения

Реальные фото из открытых товарных предложений, когда доступны. Наличие фотографии не доказывает совпадение с товаром китайской фабрики. Для непроверенных изображений остаётся ссылка на продавца.
